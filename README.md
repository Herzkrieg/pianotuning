# pianotuning

Static website for a local piano technician and tuning support service.

## Android tuner app

The [`android/`](android) directory contains a Rust workspace for the PianoTuner
Android app: `tuner-core` (DSP and tuning maths) and `pianotuner` (egui/cpal
Android shell). See [android/README.md](android/README.md) for build and usage
instructions.
